# Cloud Computing: Fundamentos e Infraestructuras - Prácticas

Este es el repositorio de las prácticas de la asignatura de Cloud Computing: Fundamentos e Infraestructuras.

## Descripción del proyecto

Este proyecto consiste en desarrollar una aplicación que permita a la empresa Hamari S.L. gestionar las ventas de sus productos, de forma que permita a los proveedores promocionar sus experiencias de forma sencilla y permita que los clientes los adquieran facilmente.
